# Function Reference

What every button on the calculator does. Trig follows the current
rad/deg setting (default: radians); the `2ⁿᵈ` key swaps in the
hyperbolic functions.

## General

| Key | Action |
|-----|--------|
| `C` | Clear display (resets to `0`) |
| `±` | Toggle sign of the current value |
| `%` | Divide current value by 100 |
| `(`, `)` | Parentheses; `=` auto-closes any unclosed `(` |
| `EE` | Append exponent notation (`e`) |
| `=` | Evaluate; unclosed parentheses are closed first, result is added to history |

## Memory

| Key | Action |
|-----|--------|
| `mc` | Clear memory |
| `m+` | Add displayed value to memory |
| `m−` | Subtract displayed value from memory |
| `mr` | Recall memory to the display |

## Powers, roots, logs

| Key | Action |
|-----|--------|
| `x²`, `x³` | Square / cube the displayed value |
| `xʸ` | Power: enter base, press key, enter exponent, `=` |
| `eˣ` | e raised to x |
| `10ˣ` | 10 raised to x |
| `²√x`, `³√x` | Square root / cube root |
| `ʸ√x` | nth root: enter x, press key, enter n, `=` |
| `¹/x` | Reciprocal |
| `ln` | Natural logarithm |
| `log₁₀` | Base-10 logarithm |
| `x!` | Factorial |

## Trig (rad/deg aware)

| Key | 2ⁿᵈ off | 2ⁿᵈ on |
|-----|---------|--------|
| first | `sin` | `sinh` |
| second | `cos` | `cosh` |
| third | `tan` | `tanh` |

## Constants

| Key | Value |
|-----|-------|
| `π` | 3.14159265… |
| `e` | 2.71828182… |

## Errors

Anything that can't be evaluated (e.g. division by zero, `√` of a
negative, mismatched input) shows `Error` on the display instead of a
result.
